## 用户反馈（21:04）：比赛是假的 → 接入 ESPN 真实数据源
- 用户指出"现在根本没有这些比赛"：平台一直用模拟引擎伪造"进行中"比赛（利物浦vs纽卡59' 之类）。
- 决策：接真实数据（ESPN 公开接口，无需 key）+ 无真实比赛时显示真实赛程/结果并明确标注。
- ESPN 接口要点：
  - scoreboard: /apis/site/v2/sports/soccer/{eng.1|esp.1|ita.1|ger.1|fra.1}/scoreboard（?dates= 参数常返回空，默认返回最近赛程）
  - summary?event={id}: keyEvents（进球/红黄牌/换人+分钟+球员）、boxscore.teams[].statistics（控球/射门/射正/角球/犯规/牌）、rosters（20人名单，无年龄/位置）
  - **浏览器 UA（Mozilla/Chrome）会被 403，必须用 curl 风格 UA 或 urllib 默认 UA**
- 实现：app/ingest/espn.py（UPSERT by provider_event_id，同步后删 provider!='espn' 的模拟比赛）；
  Match/Team/Player 加 provider 等列 + core/db.ensure_schema() 自动 ALTER（兼容旧库）；
  effective_state/_score/_live_stats 优先真实值；main.py 启动线程周期同步（REAL_DATA/REAL_SYNC_INTERVAL）；
  前端 DataSource 徽标/页脚 + 无进行中比赛时自动切分组。
